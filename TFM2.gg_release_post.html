Teamfight Manager 2 0.4.7 대응

TFM2.gg 패키지 배포

정말 유용하게 사용하던 좋은 자료였는데, 원작자님이 모든 자료를 삭제하셔서 제가 이어받아 0.4.7 대응 패치와 설치 편의성 개선까지 진행했습니다.

이번 버전부터는 기존의 단순 파일 덮어쓰기 방식 대신, 더욱 편리하게 관리하실 수 있도록 통합 설치 도구 형태로 제작했습니다. 설치, 복구, 제거, 아이템 자동 설정 애드온 설치, 원격 업데이트까지 한 화면에서 관리할 수 있습니다.

지원 버전: Teamfight Manager 2 0.4.7 통합 설치 도구 포함 원격 업데이트 지원

다운로드 안내

GitHub Releases 페이지 패키지 직접 다운로드 Google Drive 다운로드 소스코드 저장소

주요 기능

설치 경로 자동 감지 현재 설치된 팀파이트 매니저 2의 경로를 자동으로 찾습니다.
호환성 표시 현재 게임 버전이 0.4.7 기준과 맞는지 GUI 화면에서 바로 알려줍니다.
통합 관리 TFM2.gg 메타 대시보드와 아이템 자동 설정 애드온 모드 설치를 지원합니다.
자가 복구 및 제거 설치 상태 확인 후 문제가 있을 경우 복구하거나 안전하게 제거할 수 있습니다. 작업 시 기존 파일은 자동 백업됩니다.
원격 업데이트 GitHub에 새로운 버전이 등록되면 설치 도구 내에서 바로 업데이트할 수 있습니다.
README 확인 설치 도구 안에서 사용 설명을 바로 확인할 수 있습니다.

설치 방법

  1. 상단의 직접 다운로드 링크를 통해 ZIP 파일을 다운로드합니다.
  2. 다운로드한 파일의 압축을 해제합니다.
  3. TFM2GGInstaller.exe 파일을 실행합니다.
  4. 인식된 게임 경로가 올바른지 확인합니다.
  5. 우측 상단에 호환 표시가 나타나면 설치 버튼을 클릭합니다.

기본 감지 설치 경로:
C:\Program Files (x86)\Steam\steamapps\common\Teamfight Manager2

주의 사항

  • 본 도구는 Teamfight Manager 2 0.4.7 버전을 기준으로 제작되었습니다. 다른 버전에서는 호환 여부 표시를 반드시 확인해 주세요.
  • 스팀 기본 경로처럼 Program Files 폴더 내부에 설치된 경우 권한 문제가 발생할 수 있으니, 필요하면 관리자 권한으로 실행해 주세요.
  • 본 도구는 비공식 모드입니다. 실행 중 오류가 발생할 경우 설치 도구 내의 제거 또는 복구 기능을 이용해 주세요.
  • 개인 배포용 EXE 파일 특성상 별도의 인증서 서명이 없어 최초 실행 시 Windows SmartScreen 경고가 나타날 수 있습니다. 공식 배포 링크에서 받은 파일인지 확인한 뒤 실행해 주세요.

이번 업데이트 변경 사항

  • 0.4.7 버전 대응 및 세이브/메타 데이터 불일치 오류 수정
  • 대시보드와 실제 게임 진행 세이브데이터의 동기화 오차 보강
  • 아이템 자동 설정 애드온 모드의 0.4.7 버전 호환성 패치
  • GitHub 연동을 통한 최신 버전 원격 업데이트 기능 추가
  • 설치, 복구, 제거, 업데이트를 한 화면에서 처리하는 통합 설치 도구 추가
